\# FSD Team Collaboration Using GitHub



\## Project Title

Team Collaboration Using GitHub



\## Aim

To understand collaborative software development using GitHub through branches, Issues, Pull Requests, code reviews, and project documentation.

\## Project Description

This project demonstrates how developers collaborate on a web application using Git and GitHub. Developers work on separate feature branches, commit changes, and submit Pull Requests for review before merging them into the main branch.

\## Git Workflow

1\. Create a feature branch.

2\. Develop and modify project files.

3\. Stage and commit changes.

4\. Push the feature branch to GitHub.

5\. Create a Pull Request.

6\. Review and merge the changes into `main`.
